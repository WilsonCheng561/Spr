## git报错 403permission denied 处理
生成ssh key
ssh-keygen -t rsa -b 4096 -C "cwz1605672099@gmail.com" -f ~/.ssh/id_rsa_wilson
为当前 repo 显式指定使用该密钥
nano ~/.ssh/config

Host github-wilson
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_rsa_wilson
    IdentitiesOnly yes

cat ~/.ssh/id_rsa.pub
复制到github deploy key
